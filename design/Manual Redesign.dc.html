Basis-Setup

Voraussetzungen keine
Dauer ≈ 1 Stunde
Sprache Deutsch · English

Die komplette Kursumgebung in fünf Schritten: Claude Code in einer Sandbox, dein Repo ausgecheckt, n8n am Laufen, und beide miteinander verbunden. Jeder Schritt verlinkt ein vollständiges Manual — das durcharbeiten, dann hierher zurück.

Rechne mit einer Stunde, überwiegend Downloads.

Installation

1

Claude Code in einer Sandbox

Manual: Claude Sandbox →

Claude-Code-CLI und Dockers sbx installieren, dann sbx login und claude. Melde dich mit deinem Abo an, nicht mit einem API-Key.

bash copy 
$ npm install -g @anthropic-ai/claude-code
$ sbx login
$ claude
Check Fertig, wenn claude --version und sbx --version beide antworten.
2

Dein Repo auf deiner Maschine

Manual: Git-Repo-Zugang →

SSH-Key erzeugen, bei Azure DevOps registrieren, dein Repo klonen. Ihr bekommt je ein eigenes Repo, benannt nach euch oder einem Kürzel, das am Kursmorgen vergeben wird.

3

n8n auf Docker

Container starten, Port prüfen, ersten Workflow anlegen.
